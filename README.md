# Rock Paper Scissors Game 🎮

A simple, interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript (DOM Manipulation).

## 🚀 Live Demo
Play the game live here: [Anshika's Rock Paper Scissors Game](https://anshika-rock-paper-scissors.netlify.app)

## ✨ Features
- Interactive UI with custom images for Rock, Paper, and Scissors.
- Real-time score tracking (User vs Computer).
- Dynamic status message displaying round results.

## 🛠️ Tech Stack
- **HTML5**: Game structure
- **CSS3**: Styling and layout
- **JavaScript**: DOM manipulation and game logic
